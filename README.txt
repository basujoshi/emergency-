HAMRO NEPAL — MULTI-PAGE WEBSITE

All pages are separate HTML files and each page contains its own topic-specific information. The shared style.css provides consistent design.

HOW TO UPLOAD TO GITHUB PAGES
1. Extract this ZIP.
2. Upload every .html file and style.css to the same repository root (do not place them in a subfolder).
3. Keep index.html in the repository root.
4. In GitHub repository Settings > Pages, select the branch and /(root), then save.
5. Open the published site URL.

Pages: Home, About Nepal, Geography, History, Provinces & Districts, Government, Economy, Tourism, Culture & Languages, Festivals, Nepali Food, National Symbols, Quick Facts, Education & Tech, Wildlife & Nature, Official Links.

Note: Current office holders and public information may change. Use the official links on the Government and Official Links pages to verify current details. The flag is a decorative SVG approximation, not a legal production template.
